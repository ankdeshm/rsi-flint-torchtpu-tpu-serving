# `RecursiveSI/flint` (`40B-A2.5B` MoE) High-Throughput & Long-Context (`128K`) Serving on Cloud TPU (`v7x-16` Ironwood & `v5p-16`)

End-to-end production serving stack, `[128, 128]` dynamic Block-FP8 checkpoint converter, fused VMEM Pallas `router_topk` (`256`-expert) kernel, sub-host VFIO / metadata replica isolation, prefix-trunk affinity HTTP gateway, and empirical serving benchmarks up to **`131,072` (`128K`) context** for **[`RecursiveSI/flint`](https://huggingface.co/RecursiveSI/flint)** (`39.8B` total / `~2.5B` active MoE) on **Google Cloud TPU `v7x-16` (`Ironwood`, `2x2x4`)** and **TPU `v5p-16` (`2x2x4`)** using **`sglang-torchtpu` + TorchTPU `0.2.0` GA**.

## 2. How Baseline Serving Was Optimized (`Stock SGLang` → `33,421.5 tok/s` & `117.8M` KV Tokens)

| Optimization Step | What Changed Over Stock `sglang_tpu` + `flint_sglang` Baseline | Code Anchor | Ablation / Proof JSON |
|---|---|---|---|
| **1. Override `mem_fraction_static=0.40` Trap** | Stock `sglang_tpu` caps HBM at `40%` (`~38 GiB`), OOMing `BF16 TP=2` and starving KV cache; tuned to `0.82–0.88` to unlock `40–68 GiB/rank` paged KV cache | [`launch_host_replicas.py`](./v7x/scripts/launch_host_replicas.py) · [`bench_flint_v5p.py#L379`](./v5p/scripts/bench_flint_v5p.py#L379-L440) | [`smoke_bf16_tp2_1rep.json`](./v7x/results/smoke_bf16_tp2_1rep.json) |
| **2. Fused VMEM Pallas `router_topk` (`256` Experts)** | Replaced Python `torch.topk` + dynamic `gather` across 47 MoE layers with `sglang_tpu_pallas::router_topk` (decode) + 6-round `argmax` mask (prefill) | [`patch_flint_router_topk.py#L30`](./v7x/scripts/patch_flint_router_topk.py#L30-L68) | [`ablation_stock_router_tp2_1chip.json`](./v7x/results/ablation_stock_router_tp2_1chip.json) |
| **3. `FP8` (`e4m3`) KV Cache + Hybrid `swa_ratio=0.10`** | Doubled KV capacity with `fp8_e4m3` paged KV (`pallas_tpu_rpa_v3`) and sized SWA pool to `0.10` (`513`-token window on 35/49 layers) -> **`117.8M` KV tokens/slice** | [`orchestrate_v7x_slice.py#L141`](./v7x/scripts/orchestrate_v7x_slice.py#L141-L215) | [`ablation_bf16kv_tp2_1chip.json`](./v7x/results/ablation_bf16kv_tp2_1chip.json) · [`ablation_swa010_tp2_1chip.json`](./v7x/results/ablation_swa010_tp2_1chip.json) |
| **4. Zero-Padding `[128, 128]` Block-FP8 Converter (`4.6s`)** | Parallel 15-shard converter (`79.6 GB -> 40.4 GB`), unlocking single-TC `TP=1 × DP=32` on `v7x` & single-chip `TP=1 × DP=16` on `v5p` + `#1` `64K/128K` throughput | [`convert_flint_fp8.py#L35`](./v7x/scripts/convert_flint_fp8.py#L35-L72) · [`quantize_flint_fp8.py#L60`](./v5p/scripts/quantize_flint_fp8.py#L60-L105) | [`fullslice_fp8_tp2_dp16_swa010.json`](./v7x/results/fullslice_fp8_tp2_dp16_swa010.json) |
| **5. Sub-Host VFIO Isolation + Trunk-Affinity Gateway** | `LD_PRELOAD` `metadata_hook.so` + `/dev/vfio/0..7` launches `16` zero-ICI intra-package `TP=2` replicas across `v7x-16` behind disjoint prefix-trunk affinity routing | [`metadata_hook.c`](./v7x/scripts/metadata_hook.c) · [`gateway_flint_v7x.py`](./v7x/scripts/gateway_flint_v7x.py) | [`fullslice_bf16_tp2_dp16.json`](./v7x/results/fullslice_bf16_tp2_dp16.json) |
