# `RecursiveSI/flint` (`40B-A2.5B` MoE) Serving on TPU `v7x-16` & `v5p-16`

Serving stacks (**`sglang-torchtpu`** sub-host zero-ICI `TP×DP` and **`vllm-torchtpu` `v0.32.0`** native multi-host Ray `EP=32`/`EP=16`), `[128, 128]` dynamic Block-FP8 checkpoint converter, fused VMEM Pallas `router_topk` (`256`-expert) & RPA v3 (`head_dim=128`) `attention_sink` kernels, sub-host VFIO / metadata replica isolation, prefix-trunk affinity HTTP gateway, and serving benchmarks up to **`131,072` (`128K`) context** for **[`RecursiveSI/flint`](https://huggingface.co/RecursiveSI/flint)** (`39.8B` total / `~2.5B` active MoE) on **Google Cloud TPU `v7x-16` (`2x2x4`)** and **TPU `v5p-16` (`2x2x4`)**.

## 2. Optimization Summary

| Optimization Step | Change Over Stock Baseline | Code Anchor | Ablation / Result JSON |
|---|---|---|---|
| **1. Override `mem_fraction_static=0.40`** | Stock `sglang_tpu` caps HBM at `40%` (`~38 GiB`), causing OOM on `BF16 TP=2` and limiting KV cache; set to `0.82–0.88` to allocate `40–68 GiB/rank` paged KV cache | [`launch_host_replicas.py`](./v7x/scripts/launch_host_replicas.py) · [`bench_flint_v5p.py#L379`](./v5p/scripts/bench_flint_v5p.py#L379-L440) | [`smoke_bf16_tp2_1rep.json`](./v7x/results/smoke_bf16_tp2_1rep.json) |
| **2. Fused VMEM Pallas `router_topk` (`256` Experts)** | Replaced Python `torch.topk` + dynamic `gather` across 47 MoE layers with `sglang_tpu_pallas::router_topk` (decode) + 6-round `argmax` mask (prefill) | [`patch_flint_router_topk.py#L30`](./v7x/scripts/patch_flint_router_topk.py#L30-L68) | [`ablation_stock_router_tp2_1chip.json`](./v7x/results/ablation_stock_router_tp2_1chip.json) |
| **3. `FP8` (`e4m3`) KV Cache + Hybrid `swa_ratio=0.10`** | Expanded KV capacity with `fp8_e4m3` paged KV (`pallas_tpu_rpa_v3`) and tuned SWA pool to `0.10` (`513`-token window on 35/49 layers) -> **`117.8M` KV tokens/slice** | [`orchestrate_v7x_slice.py#L141`](./v7x/scripts/orchestrate_v7x_slice.py#L141-L215) | [`ablation_bf16kv_tp2_1chip.json`](./v7x/results/ablation_bf16kv_tp2_1chip.json) · [`ablation_swa010_tp2_1chip.json`](./v7x/results/ablation_swa010_tp2_1chip.json) |
| **4. `[128, 128]` Block-FP8 Converter (`4.6s`)** | Parallel 15-shard converter (`79.6 GB -> 40.4 GB`), enabling single-TC `TP=1 × DP=32` on `v7x` & single-chip `TP=1 × DP=16` on `v5p` and `7,225.0` / `5,172.5` tok/s at `64K` / `128K` | [`convert_flint_fp8.py#L35`](./v7x/scripts/convert_flint_fp8.py#L35-L72) · [`quantize_flint_fp8.py#L60`](./v5p/scripts/quantize_flint_fp8.py#L60-L105) | [`fullslice_fp8_tp2_dp16_swa010.json`](./v7x/results/fullslice_fp8_tp2_dp16_swa010.json) |
| **5. Sub-Host VFIO Isolation + Trunk-Affinity Gateway** | `LD_PRELOAD` `metadata_hook.so` + `/dev/vfio/0..7` launches `16` intra-package `TP=2` replicas across `v7x-16` behind disjoint prefix-trunk affinity routing | [`metadata_hook.c`](./v7x/scripts/metadata_hook.c) · [`gateway_flint_v7x.py`](./v7x/scripts/gateway_flint_v7x.py) | [`fullslice_bf16_tp2_dp16.json`](./v7x/results/fullslice_bf16_tp2_dp16.json) |
| **6. Intra-Chip `DP-Attention=32` (`v7x`) & `mrr=96` Batching (`v5p`)** | Spaced ZMQ TCP IPC ports (`30000 + r*20`) for `4`/host `--enable-dp-attention --dp-size 2` (`32` `attn_tp=1` ranks -> **`39,520.7` tok/s** on `v7x-16`); raised `mrr=96, swa=0.10` (`8×96=768` decode slots -> **`18,940.7` tok/s** on `v5p-16`, `+85.4%`) | [`launch_host_replicas.py#L225`](./v7x/scripts/launch_host_replicas.py#L225-L310) · [`bench_flint_v5p.py#L1310`](./v5p/scripts/bench_flint_v5p.py#L1310-L1430) | [`fullslice_fp8_tp2_dpattn32_swa010.json`](./v7x/results/fullslice_fp8_tp2_dpattn32_swa010.json) · [`v5p16_slice16_opt_r2_slice16_pod0.jsonl`](./v5p/results/raw/v5p16_slice16_opt_r2_slice16_pod0.jsonl) |
| **7. Native `vllm-torchtpu` `FlintForCausalLM` + RPA v3 `hd=128` Sink + `EP=32`/`EP=16`** | Added native `vllm` model/config registration and Pallas RPA v3 `head_dim=128` online-softmax `attention_sink` kernel, unlocking single-endpoint `TP=1` BF16 & FP8/W8A16 across 4 hosts (`27,091.9` tok/s on `v7x-16`; `9,470.7` tok/s on `v5p-16`) | [`install_flint_vllm.py#L753`](./vllm/scripts/install_flint_vllm.py#L753-L912) · [`run_flint_vllm_multihost_suite.py`](./vllm/scripts/run_flint_vllm_multihost_suite.py) | [`vllm_bf16_tp1_dp32_ep32_fp8kv.json`](./vllm/results/v7x-16/vllm_bf16_tp1_dp32_ep32_fp8kv.json) · [`vllm_bf16_tp1_dp16_ep16_fp8kv.json`](./vllm/results/v5p-16/vllm_bf16_tp1_dp16_ep16_fp8kv.json) |
